# Implementation interface (native modules)

Python package `iimt`, native modules `iimt._control`, `iimt._model`, `iimt._viewer`. Python API owns a spawned controller process and separate spawned viewer; native servo/read threads do not call Python. Parent only starts localhost IPC, no direct robot SDK.

## _control (native C++)
`Controller(arms: list[dict])`; `connect()`; `get_state() -> dict`; `execute(times: list[float], positions: list[list[float]], start_unix_ns: int, velocities=[], accelerations=[]) -> int goal_id`; `cancel()`; `result() -> dict`; `diagnostics() -> dict`; `drain_samples() -> list[dict]`; `close()`.
Canonical arm/column order matches arms config, six joints each in `joint_names` order (SDK axis order). Python reorders user trajectory names before execute. Config keys: name, ip, port=29999, sdk_library, command_rate=125, read_rate=125, read_timeout=.1, state_timeout=.2, enable_motion=false, servo_a=5, servo_v=3, lookahead_time=.012, gain=0, advance_ms=0, start_tolerance=.02, path_tolerance=3, goal_tolerance=.003, goal_time_tolerance=2, jitter_warning=.004, min_position/max_position/max_velocity/max_acceleration/max_step six arrays. Default vectors from current ROS profiles. Connect must acquire fresh state, no power/brake commands. Zero start means now plus safe lead (.1s); future start absolute UTC accepted, mapped once to steady clock. Old timestamps rejected. Single active goal, no preemption. Terminal measured endpoint, abort stale/path/limit, cancel all arms. Stop/Clear both attempted after sends; failures latch fault and keep original cause.
State shape: `{'arms': [{'name':str,'joint_names':list,'positions':list,'velocities':list,'stamp_unix_ns':int,'received_monotonic_ns':int,'age_s':float,'valid':bool}], 'active':bool}`. Failed reads never refresh timestamps. Each sample same per-arm dict with optional goal_id, desired_positions, nominal_elapsed_s; bounded history and overflow counter. Result shape `{'goal_id':int,'status':'idle|running|succeeded|cancelled|aborted','message':str,'start_unix_ns':int}`; may add timing/per-arm detail. Diagnostics dict arms stats, counters, message. No mock flag/branch. SDK dynamic load platform native; TCP reader native bounded sockets. GIL released for blocking methods. Dedicated CMake `cpp/control.cmake` adds module `_control`, install DESTINATION iimt; own sources in cpp/control/.

## _model (native C++)
`Model(urdf_path: str, joint_names: list[str], package_paths: dict[str,str]={}, disabled_collisions: list[tuple[str,str]]=[], floor_z=None, workspace=None)`.
workspace either None or `[xmin,xmax,ymin,ymax]` with no ceiling. Model stores six/twelve controlled joints, all other movable joints unsupported; fixed links allowed. Strict missing/unsupported geometry errors. `limits() -> {'lower':list,'upper':list,'velocity':list}`; `check(q) -> {'valid':bool,'collisions':list}`; `plan(start, goal, timeout=5., resolution=.02) -> list[list[float]]` returns path incl endpoints or raises. Full FCL triangle geometry, URDF primitives, FK joint origins/axes. Disabled pairs explicit, only fixed robot bases can touch floor via provided disabled_pairs including __floor__. No whole-arm/inter-arm implicit disabling. `geometry(q) -> list[dict]` entries `{name,vertices:[[x,y,z]...],triangles:[[i,j,k]...],color:[r,g,b,a]}` world-coordinate visual meshes for small viewer, fallback collision geometry if no visual. `transforms(q)` optional. Dedicated cpp/model.cmake adds/installs module; cpp/model/ ownership.

## _viewer (native C++)
Minimal GLFW/OpenGL renderer exposed via pybind: `Viewer(title,width=1100,height=800)`; `update(meshes, target, lower, upper, status, workspace=None, floor_z=None) -> dict` renders a frame, returns `{open:bool,target:list,action:None|'plan'|'execute'|'cancel'}`; `close()`. Sliders are target only. UI native Dear ImGui; root Python viewer process supplies model.geometry for measured/planned overlay, handles plan/execution asynchronously. Native UI thread only, not servo. cpp/viewer.cmake module and cpp/viewer/ ownership.
